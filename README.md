## 📱 Características Principales

- **Arquitectura Modular Client-Side**: Navegación ágil y moderna basada en Jetpack Compose y Material 3.
- **Anime, Manga y Cine & Series**: Fuentes en vivo integradas y soporte para fuentes dinámicas personalizadas.
- **Reproductor Multimedia**: Soporte para HLS/MP4, gestos de volumen/brillo, velocidad variable y pantalla completa adaptable.
- **Gestión de Descargas**: Descargas en segundo plano con soporte para reanudar capítulos incompletos.
- **Actualizaciones Automáticas**: Detección nativa de nuevas versiones desde la app.
